# Starbucks Beverage Analytics Dashboard

## Project Overview
An interactive Power BI dashboard designed to explore Starbucks beverage data and present key metrics through clear, insightful visualizations.

## Objectives
- Analyze beverage categories and their nutritional characteristics.
- Compare average calories, sugar, and caffeine across categories.
- Explore beverage category distribution.
- Identify the five beverages with the highest caffeine content.
- Present insights through an interactive dashboard.

## Key Dashboard Features
- Total Beverage Count
- Average Sugar
- Average Calories
- Average Caffeine
- Average Calories by Beverage Category
- Starbucks Global Presence
- Beverage Category Distribution
- Average Caffeine by Category
- Top 5 Highest Caffeine Beverages

## Tools & Technologies
- Microsoft Power BI
- Power Query for data cleaning and transformation
- DAX for measures and calculations, where applicable
- Data visualization and dashboard design
